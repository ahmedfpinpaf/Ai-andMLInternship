# YoungDevInterns – Machine Learning & Artificial Intelligence Tasks

This repository contains my solutions and implementations for the **YoungDevInterns 01 Month Remote Internship** tasks in **Machine Learning** and **Artificial Intelligence**.

The internship task sheets are organized into **Basic, Intermediate, and Expert** levels. The Machine Learning task sheet requires a repository named `YoungDevInterns_Machine Learning_Tasks`, while the Artificial Intelligence task sheet requires `YoungDevInterns_Artificial Intelligence_Tasks`.

# 🤖 Machine Learning Tasks

## Basic Level

### Task 1 – Implement a Simple Linear Regression

**Objective:** Create a linear regression model.

**Requirements:**
- Use a library such as scikit-learn.
- Fit a linear regression model to a small dataset.
- Plot the regression line.
- Make predictions.

**Skills:** Regression, model fitting, prediction, data visualization.

---

### Task 2 – Classify Data with a Decision Tree

**Objective:** Train a decision tree classifier.

**Requirements:**
- Use scikit-learn.
- Use a dataset such as Iris.
- Evaluate the model using:
  - Accuracy
  - Confusion matrix

**Skills:** Classification, decision trees, model evaluation.

---

### Task 3 – Visualize Data with a Scatter Plot

**Objective:** Create a scatter plot to visualize relationships in data.

**Requirements:**
- Use Matplotlib or Seaborn.
- Plot two features.
- Analyze how the features are correlated.

**Skills:** Data visualization, exploratory data analysis, correlation analysis.

---

## Intermediate Level

### Task 1 – Build a Model with Cross-Validation

**Objective:** Evaluate model performance using cross-validation.

**Requirements:**
- Implement k-fold cross-validation using scikit-learn.
- Compare performance metrics across folds.
- Metrics may include:
  - Accuracy
  - F1-score

---

### Task 2 – Preprocess Data for Machine Learning

**Objective:** Clean and prepare data for modeling.

**Requirements:**
- Handle missing values.
- Normalize features.
- Encode categorical variables.
- Split the data into training and testing sets.

**Skills:** Data cleaning, feature scaling, categorical encoding, train/test splitting.

---

### Task 3 – Create a Classification Report

**Objective:** Generate a detailed classification report.

**Requirements:**
- Train a classification model using scikit-learn.
- Generate precision, recall, and F1-score for each class.

---

## Expert Level

### Task 1 – Develop a Neural Network for Classification

**Objective:** Build and train a neural network.

**Requirements:**
- Use TensorFlow or PyTorch.
- Create a neural network for classification.
- Train the model.
- Evaluate its performance on a test set.

---

### Task 2 – Implement Hyperparameter Tuning

**Objective:** Optimize model hyperparameters.

**Requirements:**
- Use `GridSearchCV` or `RandomizedSearchCV`.
- Find suitable hyperparameters.
- Evaluate how different hyperparameters affect model performance.

---

### Task 3 – Deploy a Machine Learning Model

**Objective:** Deploy a trained model as a web service.

**Requirements:**
- Create an API using Flask or FastAPI.
- Deploy the API to a cloud platform such as:
  - AWS
  - Azure
  - Google Cloud

# 🚀 How to Run the Projects

## 1. Clone the Repository

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
cd <YOUR-REPOSITORY-NAME>
```

## 2. Create a Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux/macOS

```bash
source venv/bin/activate
```

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## 4. Run a Task

Navigate to the required task folder and run its Python file or notebook.

For example:

```bash
cd Machine_Learning/Basic/Task_1_Linear_Regression
python main.py
```
